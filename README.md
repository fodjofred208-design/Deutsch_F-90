# 🇩🇪 DEUTSCH 90

## De zéro → A1 solide en 90 jours

**Deutsch 90** est une application web autonome d’apprentissage de l’allemand conçue pour accompagner un débutant absolu pendant **90 jours**, à raison de **2 heures par jour**, soit environ **180 heures**.

L’application est contenue dans un seul fichier HTML :

```text
Deutsch90_A1.html
```

Elle ne nécessite ni compte, ni installation, ni backend, ni serveur local pour ses fonctions essentielles.

## 🎯 Objectif pédagogique

Deutsch 90 accompagne progressivement l’apprenant de la découverte des premiers mots vers une base A1 pratique :

- vocabulaire quotidien ;
- articles, pluriels et accusatif ;
- phrases simples et ordre des mots ;
- questions et réponses ;
- verbes modaux et séparables ;
- compréhension écrite et orale ;
- prononciation et expression orale ;
- rédaction de textes de plus en plus longs ;
- situations concrètes : restaurant, gare, achats, téléphone, santé et administration ;
- culture, géographie, histoire, institutions, éducation, économie et société allemandes.

Le programme présente les différences régionales, sociales et individuelles. Il distingue une **pratique courante** d’une **règle universelle** et évite de réduire les habitants à des stéréotypes.

---

## 🗓️ Structure du programme

Le programme contient exactement **90 jours** :

- **Semaines 1 à 12 :** 12 modules de 7 jours = 84 jours ;
- **Days 85–90 :** phase finale de consolidation et d’évaluation ;
- **Chaque 7e jour :** révision et test ;
- **Day 90 :** évaluation finale A1 locale.

Chaque jour possède :

- numéro et titre ;
- objectifs d’apprentissage ;
- vocabulaire réel ;
- concept grammatical ;
- tâche d’écoute ;
- tâche de conversation ;
- tâche de prononciation ;
- activité d’écriture ;
- contenu culturel ou historique ;
- ressource recommandée ;
- mini-exercice ;
- checkpoint de fin de journée ;
- zone de notes personnelles.

### Organisation quotidienne exacte

| Bloc | Durée |
|---|---:|
| 🧠 Vocabulaire | 20 min |
| 📚 Grammaire | 25 min |
| 🎧 Écoute | 25 min |
| 🗣️ Expression orale / prononciation | 20 min |
| ✍️ Écriture | 15 min |
| 🇩🇪 Culture / histoire / connaissances générales | 15 min |
| **Total** | **120 min** |

## ⚙️ Fonctionnalités interactives

### Progression

- marquer explicitement une journée comme terminée ;
- marquer une journée comme incomplète ;
- calcul automatique des jours, heures et pourcentage ;
- bouton **Continue Learning** ;
- journée recommandée actuelle ;
- dernier cours terminé ;
- indicateur A1 approximatif ;
- carte visuelle des 90 jours ;
- progression détaillée de chaque journée, partie par partie ;
- historique des validations et des tests ;
- enregistrement local des parties Vocabulary, Grammar, Listening, Speaking, Pronunciation, Writing, Culture et Exercise.

### Streak

Le streak est mis à jour uniquement lorsqu’une journée est réellement marquée comme terminée :

- progression sur des jours calendaires consécutifs ;
- remise à 1 après un jour manqué ;
- streak actuel ;
- meilleur streak ;
- aucune augmentation lorsque l’application est simplement ouverte.

### Notes quotidiennes

Chaque jour possède une zone locale pour répondre à :

- What did I learn today?
- What mistakes did I make?
- New vocabulary
- Questions

### Vocabulary

- flashcards ;
- Show Answer ;
- I Know ;
- Review Again ;
- Next / Previous ;
- catégories ;
- recherche ;
- filtre des cartes dues ;
- suivi par box ;
- répétition espacée simple.

Les noms suivent le format :

```text
der Tisch
 die Tische
 table
```

Les verbes affichent une forme passée repère et les adjectifs leur traduction. [Anki](https://apps.ankiweb.net/) est recommandé pour une répétition espacée plus avancée.

### Grammar

La bibliothèque contient notamment :

- pronoms personnels ;
- sein et haben ;
- verbes réguliers ;
- articles définis et indéfinis ;
- nominatif ;
- accusatif ;
- introduction au datif ;
- pluriels ;
- nicht et kein ;
- ordre des mots ;
- questions oui/non et W-Fragen ;
- verbes modaux ;
- verbes séparables ;
- prépositions ;
- expressions temporelles ;
- conjonctions ;
- possessifs.

Chaque thème contient une explication, des exemples, un mini-exercice, une réponse, des erreurs fréquentes et un conseil d’étude.

### Listening

La workflow est conçue pour être réutilisée :

1. écouter sans sous-titres ;
2. écouter avec sous-titres ;
3. identifier le vocabulaire ;
4. répéter les phrases ;
5. répondre à des questions ;
6. noter le résultat.

L’application utilise des liens légitimes vers des ressources externes et n’intègre pas illégalement de contenu audio protégé. `SpeechSynthesis` est utilisé lorsqu’une voix allemande est disponible ; sinon un message de secours invite à utiliser les liens officiels ou la pratique manuelle.

### Assistance vocale renforcée

L’assistant vocal est disponible dans les leçons, les cartes de vocabulaire, les exemples de grammaire, la page Listening et la page Speaking :

- lecture du vocabulaire allemand avec article et pluriel ;
- lecture de phrases modèles ;
- bouton **Hear lesson** pour entendre le script allemand d’une journée ;
- pause, reprise, arrêt et actualisation des voix disponibles ;
- choix de la voix installée par le navigateur ;
- choix de la langue allemand/français ;
- vitesse lente, confortable ou normale ;
- détection explicite d’une voix allemande ;
- fallback manuel si SpeechSynthesis n’est pas disponible.

La voix ne remplace pas les ressources audio officielles : elle sert à répéter plus souvent et à rendre chaque bloc plus actif.

### Speaking

Les scénarios comprennent :

- se présenter ;
- parler de sa famille ;
- décrire une chambre ;
- commander au restaurant ;
- demander son chemin ;
- acheter un vêtement ;
- parler de ses loisirs ;
- prendre un rendez-vous médical ;
- raconter sa routine.

Le microphone utilise `MediaRecorder` uniquement si le navigateur le supporte. Il reste optionnel et affiche :

> Browser microphone not supported — use the exercise manually.

### Motivation quotidienne

Chaque jour affiche un **Spruch des Tages** : un proverbe ou une phrase motivante en allemand, sa traduction, une action concrète et un bouton de lecture vocale. La motivation reste liée au travail réel : répéter, écrire, demander une clarification ou valider un petit bloc.

### Tests

Les jours de review proposent des tests de :

- vocabulaire ;
- grammaire ;
- lecture ;
- écoute ;
- expression orale ;
- culture ;
- histoire ;
- géographie.

Le test final contient :

- Lesen ;
- Hören ;
- Schreiben, avec un texte de 60–80 mots ;
- Sprechen, pendant 3–5 minutes ;
- Grammatik ;
- Wortschatz ;
- Deutschland-Kenntnisse.

Le résultat est un indicateur local d’apprentissage et **ne constitue pas un examen officiel Goethe, telc ou autre**.

## 💾 Stockage local et hors connexion

L’application utilise `localStorage` et reste utilisable sans serveur pour :

- navigation ;
- leçons ;
- flashcards ;
- quiz ;
- tests ;
- notes ;
- progression ;
- streak ;
- thèmes et réglages.

Clés principales utilisées :

```text
deutsch90_progress
deutsch90_notes
deutsch90_vocab
deutsch90_scores
deutsch90_streak
deutsch90_current_day
deutsch90_settings
deutsch90_sections
deutsch90_completion_log
```

Les données JSON corrompues sont ignorées avec des valeurs de secours afin d’éviter un crash au chargement.

### Export / import

La page Settings permet de :

- télécharger `deutsch90-backup.json` ;
- importer une sauvegarde JSON ;
- valider la structure avant restauration ;
- refuser un fichier malformé sans écraser les données existantes ;
- réinitialiser les données après confirmation explicite.
